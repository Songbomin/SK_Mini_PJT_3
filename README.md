# SK_Mini_PJT_3
# ✈️ 니가가라 AI - 맞춤형 국내 여행 일정 생성 서비스

## 📌 프로젝트 개요

- **프로젝트명**: 니가가라 AI ✈️  
- **주제**: 사용자의 취향과 일정을 반영한 LLM 기반 국내 여행 일정 자동 생성 서비스  
- **기간**: 2025년 3월 12일 ~ 3월 21일  

---

## 💡 기획 배경

여행 준비는 즐겁지만 복잡한 요소가 많아 시간과 노력이 많이 듭니다.  
**니가가라 AI**는 사용자의 취향에 맞춘 여행 일정을 자동으로 생성하고,  
실시간 날씨·교통 등 최신 데이터를 반영하여 최적의 일정을 제공합니다.  

- 복잡한 계획 없이 AI가 제안하는 코스를 따라 이동  
- 실시간 정보에 기반한 동적 일정 제공  
- 자동화된 계획을 통해 여행 준비 시간 절약  

---

## 👥 타겟 고객

- **20~30대 자유여행객**  
- **직장인 및 짧은 휴가 여행객**  
- **가족 단위 여행객 (부모/아이 동반)**  
- **여행 초보자 및 계획이 번거로운 사용자**  

---

## 📊 시장 분석

- **국내 여행 시장 규모**: 약 40조 원 (2023)  
- **AI 여행 서비스 시장**: 연 28.7% 성장 전망  

### ✅ 경쟁 서비스
트리플, 와그(WAUG), 네이버 여행+, 트립어드바이저, 트립닷컴 등

### ✅ 차별화 요소

- **✅ RAG 기반 일정 추천**: 실시간 날씨/교통/트렌드 반영  
- **✅ LLM 기반 맞춤 추천**: 개인 취향에 최적화된 일정 생성  
- **✅ STT 음성 인식**: 음성으로 여행 요청 가능  
- **✅ 카카오맵 연동**: 시각화된 동선 및 길찾기 제공  

---

## 🔧 핵심 기능

| 기능 | 설명 |
|------|------|
| 🧠 LLM 일정 생성 | 사용자 정보 기반 자동 여행 코스 생성 |
| 🖼 이미지 생성 | 맞춤형 여행 포스터, 안내 이미지 생성 |
| 🎙 음성 인식(STT) | 음성으로 일정 요청 및 챗봇 대화 |
| 🔍 RAG 적용 | 한국관광공사 API + 웹 크롤링 실시간 반영 |
| 🗺 카카오맵 API | 지도 기반 동선 시각화 및 길찾기 |

### 추가 기능
- 여행지 리뷰/SNS 트렌드 분석
- 여행 스타일(힐링, 맛집 등)별 추천
- 동행자와 협업 기능 (여행 일정 공유/조율)
